# Starter fish · first jaw specialisation

Earlier concept. The user's current **jaws 1** reference is the [stronger fang fish](../EVO_startfish_bite_tier2_v3/README.md); the newly drawn [jaws 2](../EVO_startfish_bite_tier2_v4/README.md) develops that form further.

A restrained first jaw upgrade of the [latest base fish](../EVO_startfish_base_v2/README.md). The deeper, firmer lower jaw, slightly open mouth and short ivory gripping teeth communicate a stronger bite while leaving room for later developments. The eye, body proportions, small fins, tail, lateral line, dark slate-olive back and warm sandy belly preserve the same species and illustration style.

`masters/startfish_g1_f0_k0.png` is the unmodified generated transparent PNG, showing the complete animal in side view facing right. It contains no background, text, stats or cast shadow. Dimensions, visible bounds, source reference and SHA-256 checksum are recorded in `manifest.json`.

This is an art master for later integration. Evolution rules, combat values and runtime textures are unchanged. Joint registration and movable parts have not yet been prepared.
